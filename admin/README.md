Admin Panel

This folder contains the admin panel files for the Online Complaint Registration System.

Files

- "admin_login.php" — Admin login page.
- "dashboard.php" — Displays complaint statistics.
- "manage_complaints.php" — Displays and manages registered complaints.
- "update_status.php" — Updates complaint status.
- "logout.php" — Logs out the administrator.

Purpose

The admin panel allows the administrator to view complaints and update their status, such as Pending, In Progress, Resolved, or Rejected.
