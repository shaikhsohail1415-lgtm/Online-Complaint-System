**Online Complaint Registration System**

A web-based application developed using PHP, MySQL, HTML, CSS, and Bootstrap.

Features

- User registration and login
- Secure password hashing
- Complaint submission
- Complaint status tracking
- Admin login and dashboard
- Complaint management and status updates

Technologies Used

- PHP
- MySQL / MariaDB
- HTML and CSS
- Bootstrap
- XAMPP

Local Setup

1. Install XAMPP.
2. Copy the project folder into "C:\xampp\htdocs\".
3. Create a MySQL database named "complaint_system".
4. Import the SQL file from the project's database folder, if provided.
5. Configure "db.php" with your local database settings.
6. Start Apache and MySQL.
7. Open "http://localhost:8080/online-complaint-system/" in your browser.

**Note**

This project is intended for learning and demonstration. Configure authentication and database credentials securely before deployment.
